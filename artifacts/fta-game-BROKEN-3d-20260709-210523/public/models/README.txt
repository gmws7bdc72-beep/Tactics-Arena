Football Tactics Arena 3D player model assets

Included:
- players.gltf
- textures/Studio_Ochi_Athletes_07.png through Studio_Ochi_Athletes_12.png

The game code uses only the three male GLTF root nodes:
- _gltfNode_0
- _gltfNode_46
- _gltfNode_92

The female nodes are not referenced by PlayerModel3D.tsx.
Team colors are applied dynamically by PlayerModel3D.tsx from the current saved team color and AI team jersey colors.
